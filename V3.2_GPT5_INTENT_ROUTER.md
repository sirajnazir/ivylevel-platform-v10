# v3.2 GPT-5 JSON Intent Router Enhancement

## Overview
Replaces regex-based intent detection with GPT-5 JSON classifier for robust natural language understanding. Maintains facts-first SQL routing but adds intelligent entity/phase normalization.

## Key Improvements

### 1. Natural Language Robustness
- **Synonym Normalization**: "ECs / activities / extracurriculars" → `entity:ecs`
- **Phase Variants**: "get in / got in / accepted" → `phase:final`
- **Confidence Scoring**: Low confidence (<0.8) triggers clarifying questions
- **Few-Shot Learning**: 11 golden examples guide classification

### 2. Architecture

```
User Query
    ↓
GPT-5 Classifier (packages/intent/classifier.ts)
    ↓
{intent, entity, phase, slots, confidence}
    ↓
Intent Router (apps/api/src/router/intentRouter.ts)
    ↓
Deterministic SQL Resolvers
    ↓
PostgreSQL Views (v_ecs_final, v_awards_initial, etc.)
    ↓
Formatted Response + Evidence Chips
```

### 3. Intent Types

| Intent | Entity | Phase | Example Query |
|--------|--------|-------|---------------|
| `ecs.list` | ecs | initial/final/progression | "what was my initial EC list?" |
| `awards.list` | awards | initial/final/progression | "final awards list" |
| `awards.wins` | awards | final | "which awards did I actually win?" |
| `programs.list` | programs | initial/final/progression | "initial summer programs" |
| `programs.admits` | programs | final | "which summer programs did I get in?" |
| `academics.sat` | academics | first/latest/progression | "what was my first SAT score?" |
| `academics.gpa` | academics | latest/progression | "what's my GPA?" |
| `narrative.initial` | narrative | initial | "initial narrative" |
| `kb.search` | kb | none | Generic search (RAG fallback) |

### 4. SQL Views Required

**Already Exist:**
- `v_ecs_initial`, `v_ecs_final` (from kb_items + phase filtering)
- `v_awards_initial`, `v_awards_final` (from award_targets + outcomes)
- `v_programs_initial`, `v_programs_final` (from kb_items subtype program)
- `v_sat_progression` (from sat_timeline_enum)
- `v_narrative_initial` (from kb_items subtype narrative)
- `v_transcript_initial`, `v_transcript_final`, `v_transcript_progression`
- `v_gpa_initial`, `v_gpa_final`, `v_gpa_latest`, `v_gpa_progression`

**To Be Created:**
- `v_programs_admits` (from outcomes table, program acceptances)
- `v_awards_won` (from outcomes table, award wins)
- `v_gpa_timeline` (temporal GPA view with term labels)

### 5. Observability Trace Events

1. **`intent.classify`**: GPT-5 classification
   - Input: user query
   - Output: {intent, entity, phase, confidence}
   - Metrics: latency_ms

2. **`router.route`**: Route selection
   - Input: classified intent
   - Output: resolver name
   - Metrics: latency_ms

3. **`resolver.sql`**: SQL execution
   - Input: view name, student_id
   - Output: row_count
   - Metrics: latency_ms, view_name

4. **`compose.answer`**: Response formatting
   - Input: raw rows
   - Output: formatted text + chips
   - Metrics: answer_length, chips_count

### 6. Fail-Safe UX

**Low Confidence (<0.8)**:
```json
{
  "answer": "Did you mean your initial EC list?",
  "chips": [{
    "kind": "notice",
    "text": "Low confidence 0.73"
  }],
  "traceId": "trace-abc123"
}
```

**No Data Found**:
```json
{
  "answer": "No final awards data found.",
  "chips": [{
    "kind": "evidence",
    "text": "v_awards_final"
  }],
  "hits": []
}
```

### 9. Migration from v3.1

**Before (regex-based)**:
- `services/jenny-api/src/orchestrator/intent-enum.ts`
- Hardcoded synonyms: `AWARD_SYNS`, `EC_SYNS`, etc.
- Manual if/else cascade
- No confidence scoring

**After (GPT-5 JSON)**:
- `packages/intent/classifier.ts` (AI-powered)
- `apps/api/src/router/intentRouter.ts` (centralized routing)
- Few-shot learning with 11 examples
- Confidence-based clarifications

**Backwards Compatibility**:
- Old files archived to `services/jenny-api/archive/intent-v1/`
- SQL views unchanged
- API contract unchanged (`/agent/chat`)
