## Source Data Statistics

- **Total RAW Files Processed**: 296 files
- **Session Transcripts**: 181 VTT files → 21,712 turns
- **iMessage Conversations**: 3 files → 109 turns  
- **Intelligence Files**: 117 strategic summaries
- **Speaker Attribution**: 86.8% accuracy (13.2% unknown rate)
- **Temporal Coverage**: 93 weeks across 5 coaching phases

## Coaching Patterns Captured

✅ **Strategic Planning**: Time management frameworks, goal setting  
✅ **Essay Development**: Brainstorming, editing, narrative building  
✅ **Application Strategy**: School selection, major decisions  
✅ **Emotional Support**: Stress management, confidence building  
✅ **Micro-coaching**: Quick guidance via iMessage  
✅ **Career Exploration**: Interest-to-major mapping  

## Technical Pipeline

1. **PDF Extraction**: Robust VTT parsing from flattened text
2. **Speaker Detection**: Coach/student classification with heuristics  
3. **Turn Extraction**: 21,712 conversation turns from session transcripts
4. **iMessage Processing**: Micro-coaching moments with timestamp parsing
5. **Speaker Cleanup**: Unknown→student attribution via context patterns
6. **Quality Filtering**: Strategic guidance, empathy, actionable advice
7. **PII Scrubbing**: Address/contact information replaced
8. **Deduplication**: 3,317 unique examples → 1,000 high-quality pairs

## Usage

This dataset is optimized for OpenAI fine-tuning API:

```python
import openai

# Upload training file
training_file = openai.File.create(
    file=open("finetune.train.jsonl", "rb"),
    purpose='fine-tune'
)

# Create fine-tune job
fine_tune = openai.FineTune.create(
    training_file=training_file.id,
    validation_file=validation_file.id,
    model="gpt-3.5-turbo"
)
```
