## Minor Risk Notes

### ⚠️ SAT Attempt Ordering Determinism

**Issue:** If two SAT attempts share same date, ROW_NUMBER() tie-breaking is non-deterministic

**Current View:**
```sql
CREATE VIEW compat.v_sat_timeline AS
SELECT student_id, numeric_value AS total_score, fact_date,
       ROW_NUMBER() OVER (PARTITION BY student_id ORDER BY fact_date ASC) AS attempt_number
FROM vital_facts
WHERE kind = 'sat_total_score' AND numeric_value IS NOT NULL;
```

**Fix (deterministic tie-breaking):**
```sql
CREATE OR REPLACE VIEW compat.v_sat_timeline AS
SELECT student_id, numeric_value AS total_score, fact_date,
       ROW_NUMBER() OVER (
         PARTITION BY student_id
         ORDER BY fact_date ASC, created_ts ASC, fact_id ASC  -- deterministic ties
       ) AS attempt_number,
       source_id, confidence, created_ts
FROM vital_facts
WHERE kind = 'sat_total_score' AND numeric_value IS NOT NULL;
```
