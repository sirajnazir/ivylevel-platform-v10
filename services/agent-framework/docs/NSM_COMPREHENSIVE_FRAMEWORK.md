## 🎯 NSM Hierarchy: Lagging → Leading → Vital Signs

### Lagging Indicators (Ultimate NSM)

**What:** Final outcomes that prove coach quality (measured post-graduation)

| Metric | Target | Measurement Window |
|--------|--------|-------------------|
| **Tier 1 Acceptances** (HYPSM + Ivy) | 1+ per student | April-May (senior year) |
| **Tier 2 Acceptances** (Top 20 schools) | 2+ per student | April-May (senior year) |
| **Tier 3 Acceptances** (Top 50 schools) | 5+ per student | April-May (senior year) |
| **Total Scholarship $** | $50K+ per student | April-May (senior year) |
| **Scholarship $/Hour Invested** | $500+/hr (ROI) | Post-graduation analysis |
| **Tier Improvement** | Safety → Match → Reach | Compare initial vs final college list |

**Example (Huda-2025):**
- **Initial Profile:** IvyScore 11/25, SAT 1360 → Safety/Match schools
- **Target Outcome:** Stanford acceptance (reach), $40K scholarship
- **Proof of Quality:** Tier improvement (safety → reach acceptance)
