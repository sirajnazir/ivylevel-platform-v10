# v1.2.4 Hotfix Report

## Issues Fixed

### 1. ✅ Temporal Report SQL Query
**Issue**: Internal server error due to date handling
**Fix**: Added COALESCE for null dates and proper date conversions
**Result**: Temporal report now returns valid data
```json
{
  "type": "temporal",
  "summary": {
    "totalWeeks": 15,
    "bombardmentWeeks": 8,
    "rejectionRebounds": "15",
    "avgReboundDays": 9
  }
}
```

### 2. ✅ Agent Integration for Inline Reports
**Issue**: Agent not formatting reports as markdown tables
**Fix**: Updated `fetchReportData` to return formatted markdown and added `reportData` parameter to system prompt
**Changes**:
- Added `formattedResponse` field with markdown tables
- Updated `getSystemPrompt` to accept reportData parameter
- Agent now receives pre-formatted markdown for direct use

### 3. ✅ Cron Script ts-node Issue
**Issue**: `ts-node: command not found`
**Fix**: 
- Changed shebang to `#!/usr/bin/env npx ts-node`
- Added npm script: `"cron:recompute": "cd cron && npx ts-node recompute.ts"`
**Note**: Cron script exists at `/cron/recompute.ts` but needs proper execution environment

### 4. ✅ Cache Directory Creation
**Issue**: Cache directories not auto-created
**Fix**: Added `fs.mkdirSync(cacheDir, { recursive: true })` before cache operations
**Behavior**: 
- Creates directory on first request if missing
- Caches generated reports for future requests
- Logs cache creation and storage events
