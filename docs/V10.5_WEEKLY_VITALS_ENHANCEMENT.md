## Database Schema

**Table:** `weekly_vitals`

**Enriched Columns:**
- `ec_details` (jsonb) - Array of EC objects with progressive metrics
- `award_details` (jsonb) - Array of award objects with status progression
- `program_details` (jsonb) - Array of program objects with attendance dates

**Example ec_details structure:**
```json
[
  {
    "name": "Empowering AI",
    "status": "development",  // Changes: development → launched → scaling → in_app
    "metrics": {
      "hours_per_week": 8,
      "funding_raised": 5000,  // Grows: 0 → 5K → 13K → 23K
      "participants": 0         // Grows: 0 → 25 → 44
    },
    "founded_week": 5,
    "launched_week": 25
  }
]
```

**Example award_details structure:**
```json
[
  {
    "name": "NCWiT National Awardee and Regional Winner",
    "level": "national",
    "status": "applying",     // Changes: researching → applying → submitted → winner
    "won_week": null          // Set when status = winner
  }
]
```
