### 1.3 Required Schema Changes

**New academic_vitals v2.0 structure:**

```typescript
interface AcademicVitals {
  // GPA
  gpa_weighted?: number;
  gpa_unweighted?: number;
  gpa_scale: number; // e.g., 4.0

  // Class Rank
  class_rank?: number | 'na'; // null or number or 'na'
  class_size?: number;

  // Standardized Tests
  sat_total?: number;
  sat_ebrw?: number; // Evidence-Based Reading and Writing
  sat_math?: number;
  sat_dates?: string[]; // ['12/01/2023', '03/04/2024']

  // AP Tests (by subject)
  ap_scores?: {
    subject: string;
    score: number; // 1-5
    test_date: string; // 'MM/YYYY'
    grade_level: '9' | '10' | '11' | '12';
  }[];

  // Course Load (per semester/year)
  current_courses?: {
    semester: 'fall' | 'spring' | 'full_year';
    courses: {
      subject: string; // 'ENG', 'MATH', 'SCI', etc.
      title: string;
      level: 'REG' | 'HONORS' | 'AP' | 'IB' | 'DE'; // Dual Enrollment
    }[];
  }[];

  // Historical course progression
  course_history?: {
    grade: '9' | '10' | '11' | '12';
    courses: {
      subject: string;
      title: string;
      level: 'REG' | 'HONORS' | 'AP' | 'IB';
      semester: 'fall' | 'spring' | 'full_year';
      final_grade?: string; // 'A', 'A-', 'B+', etc.
    }[];
  }[];
}
```

## Part 4: JTBD & Parent/Student Value

### 4.1 Jobs-to-be-Done Analysis

**Parent JTBD:**
> "I want to see my child's complete academic and extracurricular profile in one place, exactly as it will appear on college applications, so I can track progress and identify gaps early."

**Student JTBD:**
> "I want to track all my activities, test scores, and courses as I build them, so when application time comes, I have everything ready and don't miss any achievements."

**Coach JTBD:**
> "I need to see a student's complete Common App-aligned profile to give accurate advice on which activities to prioritize and which gaps to fill."

### 4.2 Critical Value Props

**Why these gaps matter:**

1. **Academic Data Gaps:**
   - Parents can't see test score progression (SAT, AP)
   - Can't track course rigor vs peers
   - Can't monitor GPA trends
   - **Impact:** Missed opportunities for test prep, course selection advice

2. **Missing Activities:**
   - 5 of 10 final activities not tracked in platform
   - Can't demonstrate full breadth of student engagement
   - **Impact:** Incomplete picture of student profile, potential gaps in planning

3. **Programs vs Activities:**
   - JCamp and Kode with Klossy are programs BUT also top activities
   - Current system treats them as separate, not linked
   - **Impact:** Undervalues competitive summer programs that should be prominently featured

### 4.3 High-Resonance Activities

**Based on Common App analysis, these activity TYPES resonate most:**

1. **Competitive Summer Programs** (JCamp, Kode with Klossy)
   - Selective admission
   - Industry connections
   - Skill-building
   - **Parent Value:** Prestige, networking, resume-building

2. **Community Impact** (Sunday School, Empowering AI)
   - Volunteering hours
   - Teaching/mentoring
   - Local community ties
   - **Parent Value:** Character development, giving back

3. **Content Creation** (TikTok, Podcast, Film)
   - Modern platforms
   - Measurable reach (views, likes, episodes)
   - Student voice
   - **Parent Value:** Digital literacy, self-expression, entrepreneurship

4. **Founder/Leadership** (Empowering AI, Synthoria, Folklift)
   - Initiative
   - Fundraising
   - Team building
   - **Parent Value:** Leadership development, college admissions impact
