# v1.2.0 Release Notes - Smart Precision Opportunity Recommendation Engine

## Overview
v1.2 introduces a comprehensive opportunity recommendation system that helps students discover, evaluate, and apply to summer programs, research opportunities, scholarships, and awards.

## v1.2.2 Update - Automated Opportunity Mining
Added automated mining from normalized corpus to extract real opportunity mentions, applications, and outcomes directly from transcripts, messages, and documents.

## New Features

### 1. Opportunity Catalog Service (port 4202)
- Stores and manages opportunities with rich metadata
- Supports filtering by kind, tier, category, grade level
- Batch import from CSV/Excel/JSON
- Statistics and deadline tracking

### 2. Opportunity Scorer Service (port 4203)
- Personalized scoring based on student vitals
- 5-component scoring system (100 points total):
  - Academic fit (30pts)
  - Narrative fit (25pts)
  - Strategic value (20pts)
  - Resource fit (15pts)
  - Timeline fit (10pts)
- Automatic bucketing: immediate_action, priority_pipeline, strategic_reserve, reach, safety

### 3. Opportunity Recommender Service (port 4204)
- Smart recommendations by bucket and deadline
- Bombardment strategy for morale boosts
- Discovery of new opportunities
- Track win rates and optimize future recommendations

### 4. Agent Integration
- Natural language opportunity queries
- Context-aware recommendations
- Deadline and commitment awareness
- Bombardment suggestions after rejections

## Database Schema

```sql
-- opportunities table
- id, name, kind, tier, category
- mission, requirements, recognition_level
- commitment, deadlines, source, meta

-- opportunity_scores table
- student_id, opportunity_id, total_score
- components, bucket, rationale

-- bombardment_episodes table  
- student_id, window, trigger, size
- opportunities[], outcomes, derived_metrics
```

## API Endpoints

### Main API (port 4000)
- GET `/opportunities` - List all opportunities
- GET `/opportunities/:id` - Get single opportunity
- GET `/students/:id/opportunities/recommendations` - Get personalized recommendations
- POST `/students/:id/opportunities/bombardment` - Create bombardment episode
- GET `/students/:id/opportunities/discover` - Discover new opportunities
- POST `/students/:id/opportunities/score` - Score an opportunity

## Vitals Integration
New observation types:
- `OPPORTUNITY/APPLIED` - Track applications
- `OPPORTUNITY/RESULT` - Track outcomes (won/rejected/waitlisted)
- `OPPORTUNITY/INTERESTED` - Track interest
- `BOMBARDMENT/OUTCOME` - Track bombardment results

## v1.2.2 Features - Automated Opportunity Mining

### Opportunity Miner (`mine_opportunities.ts`)
Scans normalized corpus to automatically extract:
- **Proposals**: Opportunities mentioned/suggested by Jenny
- **Applications**: When student applies to programs
- **Outcomes**: Acceptances, rejections, waitlists
- **Deadlines**: Extracted from context (±4 lines)
- **Categories**: Automatically classified (summer_program, award, research, etc.)

### Usage
```bash
# Dry run to JSONL
pnpm --filter @tools/ingest mine-opps \
  --in data/canonical/jenny-huda \
  --student huda \
  --out data/processed/jenny-huda/opportunities.jsonl \
  --dry

# Live emission to observations
pnpm --filter @tools/ingest mine-opps \
  --in data/canonical/jenny-huda \
  --student huda \
  --observe http://localhost:4000/observe \
  --out data/processed/jenny-huda/opportunities.jsonl

# Recompute vitals after mining
curl -X POST http://localhost:4000/admin/recompute-all
```

### New Vitals Fields
- `opportunities.pipeline.active`: All mentioned opportunities
- `opportunities.pipeline.applied`: Programs applied to
- `opportunities.pipeline.decisions`: Outcomes with precedence
- `opportunities.pipeline.yield`: Win rate statistics

### Observation Format
```json
{
  "type": "OPPORTUNITY" | "APPLICATION",
  "subtype": "proposal" | "applied" | "accepted" | "rejected" | "waitlisted",
  "student_id": "huda",
  "opportunity": {
    "name": "NCWIT Aspirations in Computing",
    "category": "competition_award",
    "tags": ["women-in-tech", "computing"],
    "deadline": "October 31, 2024"
  },
  "source": { "file": "03-Raw-SessionTranscripts/...", "week": 12, "span": "..." },
  "idempotency_key": "sha1_hash"
}
```
