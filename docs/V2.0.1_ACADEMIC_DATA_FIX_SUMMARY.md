---

### 2. NSM Academic Vitals Querying Wrong Tables ❌ → ✅

**Problem:** NSM was querying `kb_items` table for SAT/GPA data, but Huda's data exists in specialized v14 views.

**Before:**
```typescript
// Querying kb_items (WRONG) - returned 0/NULL
SELECT MAX(CASE WHEN subtype = 'SAT' ...) FROM kb_items
```

**After:**
```typescript
// Querying v14 views (CORRECT) - returns 1530
SELECT numeric_value FROM v_sat_enum_latest WHERE student_id = $1
SELECT gpa_unweighted, gpa_weighted FROM v_gpa_latest WHERE student_id = $1
```

**Impact:** SAT and GPA were showing as missing despite existing in database. Now correctly displays SAT 1530, GPA 3.97/4.52.

---

### 3. Incorrect AP Course Counting ❌ → ✅

**Problem:** NSM counted courses with "AP" in title, not courses with level = 'AP'.

**Before:**
```sql
WHERE course_title ILIKE '%AP%'  -- Matched 6 (5 AP + 1 Regular with "AP" in name)
```

**After:**
```sql
WHERE level = 'AP'  -- Correctly matches only 5 AP courses
```

**Impact:** AP count was inflated by 1. Now correctly shows 5 AP courses.
