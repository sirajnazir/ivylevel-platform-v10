**2.2 RAG Chips (Extracurriculars)**

```python
# Script: tools/ingest/huda_extract_rag_chips.py

import json
from openai import OpenAI

client = OpenAI()

# Read extracurricular activities from file
with open('data/canonical/huda_historical/extracurriculars.txt') as f:
    ec_text = f.read()

# Generate RAG chip using GPT-4
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system",
            "content": "Extract structured extracurricular data from the text. Return JSON with activities, roles, and dates."
        },
        {
            "role": "user",
            "content": ec_text
        }
    ]
)

rag_data = json.loads(response.choices[0].message.content)

# Generate SQL INSERT for RAG chip
chip = {
    "student_id": "huda-2025",
    "kind": "RAG",
    "source": {
        "question": "What extracurricular activities has Huda participated in?",
        "answer": rag_data["summary"],
        "confidence": 0.95,
        "details": rag_data["activities"]
    },
    "hash": hash_content(rag_data),
    "trace_id": f"import_huda_historical_{uuid4()}"
}

# Insert into database
insert_chip(chip)
```

## 📋 Validation Scenario 2: New Student Onboarding (Autonomous Multi-Agent)

### Overview

**Student:** New student starting today (e.g., "Aarav" or synthetic student)
**Goal:** Multi-agent system autonomously:
1. Conducts initial assessment
2. Generates game plan
3. Fills database with facts
4. Schedules and executes Week 1 session continuation

### Multi-Agent Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    ORCHESTRATOR AGENT                       │
│  • Coordinates all sub-agents                              │
│  • Monitors progress                                       │
│  • Handles failures/retries                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
        ┌───────────────────┼───────────────────┐
        ↓                   ↓                   ↓
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│   ASSESSMENT  │  │   GAME PLAN   │  │    SESSION    │
│     AGENT     │  │     AGENT     │  │     AGENT     │
└───────────────┘  └───────────────┘  └───────────────┘
        ↓                   ↓                   ↓
┌───────────────────────────────────────────────────────────┐
│                    DATABASE (chips, growth_events)        │
└───────────────────────────────────────────────────────────┘
```

#### 4. Orchestrator Agent
**Location:** `/services/agent-framework/src/agents/orchestrator-agent.ts`

**Responsibilities:**
1. Coordinate all agents in sequence
2. Handle errors (retry up to 3 times)
3. Log progress
4. Notify when complete

**Workflow:**
```typescript
async function onboardNewStudent(studentData: StudentData) {
  const orchestrator = new OrchestratorAgent();

  // Step 1: Assessment
  console.log("[Orchestrator] Starting assessment...");
  const assessment = await orchestrator.run(new AssessmentAgent(studentData));
  console.log("[Orchestrator] Assessment complete:", assessment.chips_created.length, "chips");

  // Step 2: Game Plan
  console.log("[Orchestrator] Generating game plan...");
  const gameplan = await orchestrator.run(new GamePlanAgent(assessment));
  console.log("[Orchestrator] Game plan complete:", gameplan.barriers_identified.length, "barriers");

  // Step 3: Week 1 Session
  console.log("[Orchestrator] Conducting Week 1 session...");
  const session = await orchestrator.run(new SessionAgent(assessment, gameplan));
  console.log("[Orchestrator] Session complete:", session.chips_created.length, "EQ chips");

  // Step 4: Verify database
  console.log("[Orchestrator] Verifying database...");
  const dbCheck = await verifyStudentData(studentData.student_id);
  console.log("[Orchestrator] Database check:", dbCheck);

  return {
    student_id: studentData.student_id,
    onboarding_complete: true,
    total_chips: dbCheck.chip_count,
    total_growth_events: dbCheck.growth_event_count,
    ivyscore: assessment.ivyscore,
    next_session_scheduled: "2025-10-31"  // Week 2
  };
}
```
