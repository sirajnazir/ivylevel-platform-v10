## Data Flow (Request → Response)

```
1. STUDENT SENDS MESSAGE
   "Can you help me with my college list?"
                   │
                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 1: PERCEPTION                                                  │
│                                                                      │
│  MessageParser.parse()                                              │
│  → intent_keywords: ['college', 'list']                             │
│  → question_type: 'strategic'                                       │
│  → urgency: 'medium'                                                │
│                                                                      │
│  StudentContextExtractor.extract(student_id)                        │
│  → grade_level: 11                                                  │
│  → current_week: 15                                                 │
│  → journey_stage: 'gameplan'                                        │
│  → rubric_score: 18                                                 │
│  → gap_to_target: 7                                                 │
│                                                                      │
│  SessionStateDetector.detect(session_id)                            │
│  → is_new_conversation: false                                       │
│  → conversation_turn: 5                                             │
│  → previous_context: "Discussed ECs and awards"                     │
│                                                                      │
│  OUTPUT: PerceptionOutput {                                         │
│    parsed_message: ParsedMessage                                    │
│    student_context: StudentContext                                  │
│    session_state: SessionState                                      │
│  }                                                                  │
└──────────────────────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 2: KNOWLEDGE                                                   │
│                                                                      │
│  StudentFactsRetriever.retrieve(student_context)                    │
│  → vitals: { gpa: 3.95, sat: 1480, ... }                           │
│  → activities: [20 ECs from kb_items]                               │
│  → awards: [6 awards won]                                           │
│  → colleges: [28 colleges researched, 0 applied yet]                │
│                                                                      │
│  CoachingIntelligenceRetriever.retrieve(context, message)           │
│  → archetype: "High-Achiever STEM Junior"                           │
│  → playbook: {                                                      │
│      assessment_framework: "27-layer assessment",                   │
│      gameplan_template: "Week 15: College List Building",           │
│      frameworks: ["College Tiering Framework", ...]                 │
│    }                                                                │
│  → tactics: ["Start with reach schools", "Safety net strategy"]    │
│  → eq_patterns: ["warmth", "specificity", "future_pacing"]         │
│                                                                      │
│  TemporalContextResolver.resolve(student_id, week=15)               │
│  → past: [14 weeks of completed activities]                        │
│  → present: [Current week 15 tasks]                                │
│  → planned: [Weeks 16-51 gameplan]                                 │
│                                                                      │
│  OUTPUT: KnowledgeOutput {                                          │
│    student_facts: StudentFacts                                      │
│    coaching_intelligence: CoachingIntelligence                      │
│    temporal_context: TemporalContext                                │
│  }                                                                  │
└──────────────────────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 3: COGNITION                                                   │
│                                                                      │
│  IntentRouter.route(parsed_message)                                 │
│  → intent: 'college_list'                                           │
│                                                                      │
│  AgentSelector.select(intent='college_list', context)               │
│  → agent: CollegeListAgent (customized for archetype)               │
│                                                                      │
│  DecisionMaker.decide(agent, perception, knowledge)                 │
│  → Calls agent.execute(perception, knowledge)                       │
│  → Agent uses playbook + frameworks + tactics                       │
│  → LLM generates response with zero-hallucination instructions      │
│  → Validates response against student_facts                         │
│                                                                      │
│  OUTPUT: AgentDecision {                                            │
│    response_text: "Based on your profile (GPA 3.95, SAT 1480,      │
│                    strong CS ECs), here's a balanced college list:  │
│                    Reach: MIT, Stanford, Carnegie Mellon...         │
│                    Target: UIUC, Georgia Tech, UT Austin...         │
│                    Safety: Purdue, Penn State, UMass...",           │
│    response_type: 'recommendation',                                 │
│    confidence: 0.92,                                                │
│    reasoning: "Used College Tiering Framework for balanced list",   │
│    sources: ['kb_items.gpa', 'kb_items.sat', ...],                 │
│    next_actions: ['save_college_list', 'schedule_research_tasks']  │
│  }                                                                  │
└──────────────────────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 4: ACTION                                                      │
│                                                                      │
│  ResponseExecutor.execute(decision)                                 │
│  → Humanizes response (adds warmth, Jenny's voice)                  │
│  → Stores in conversation_turns table                               │
│  → Returns ExecutionResult                                          │
│                                                                      │
│  StateUpdater.update(decision, context)                             │
│  → Updates session state (turn_count++)                             │
│  → Saves college list to kb_items (if requested)                    │
│  → Creates follow-up tasks (research colleges)                      │
│                                                                      │
│  EventEmitter.emit('college_list_generated', payload)               │
│  → Notifies monitoring system (logs event)                          │
│  → Notifies training system (extracts patterns)                     │
│  → Notifies evaluation system (tracks for quality scoring)          │
│                                                                      │
│  OUTPUT: ExecutionResult {                                          │
│    response: "Hey! 😊 Based on your awesome profile...",           │
│    metadata: { latency_ms: 1234, tokens_used: 543 }                │
│  }                                                                  │
└──────────────────────────────────────────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 5: INTERFACE                                                   │
│                                                                      │
│  ViewRenderer.render(executionResult, userRole='student')           │
│  → Formats as chat message                                          │
│  → Adds college list widget (interactive table)                     │
│  → Adds next steps checklist                                        │
│                                                                      │
│  NotificationManager.notify(student_id, notification)               │
│  → Sends in-app notification: "Your college list is ready!"         │
│                                                                      │
│  OUTPUT: RenderedView {                                             │
│    type: 'chat_message',                                            │
│    content: { text, widgets, actions },                             │
│    metadata: { requires_action: true }                              │
│  }                                                                  │
└──────────────────────────────────────────────────────────────────────┘
                   │
                   ▼
2. STUDENT RECEIVES RESPONSE
   "Hey! 😊 Based on your awesome profile..."
   [College List Widget]
   [Next Steps Checklist]
```

## Component Interaction (Cognition Layer Detail)

```
┌─────────────────────────────────────────────────────────────────────┐
│                   COGNITION LAYER (Decision Making)                 │
└─────────────────────────────────────────────────────────────────────┘

INPUT: PerceptionOutput + KnowledgeOutput
   │
   ▼
┌─────────────────────────────────────────────────────────────────────┐
│ AgentOrchestrator                                                   │
│                                                                     │
│  async process(perception, knowledge): AgentDecision {              │
│                                                                     │
│    // Step 1: Route to intent category                             │
│    ┌────────────────────────────────────────────┐                  │
│    │ IntentRouter.route(parsed_message)         │                  │
│    │                                            │                  │
│    │ Keywords: ['college', 'list']              │                  │
│    │ → Intent: 'college_list'                   │                  │
│    └────────────────────────────────────────────┘                  │
│                        │                                            │
│                        ▼                                            │
│    // Step 2: Select appropriate agent                             │
│    ┌────────────────────────────────────────────┐                  │
│    │ AgentSelector.select(intent, context)      │                  │
│    │                                            │                  │
│    │ Intent: 'college_list'                     │                  │
│    │ Archetype: 'High-Achiever STEM Junior'     │                  │
│    │ → Agent: CollegeListAgent                  │                  │
│    │ → Customized with archetype playbook       │                  │
│    └────────────────────────────────────────────┘                  │
│                        │                                            │
│                        ▼                                            │
│    // Step 3: Make decision using agent                            │
│    ┌────────────────────────────────────────────┐                  │
│    │ DecisionMaker.decide(agent, perception,    │                  │
│    │                      knowledge)            │                  │
│    │                                            │                  │
│    │ ┌────────────────────────────────────┐    │                  │
│    │ │ CollegeListAgent.execute()         │    │                  │
│    │ │                                    │    │                  │
│    │ │ 1. Load playbook for archetype     │    │                  │
│    │ │ 2. Build LLM prompt with:          │    │                  │
│    │ │    - Student facts (GPA, SAT, ECs) │    │                  │
│    │ │    - Coaching frameworks           │    │                  │
│    │ │    - Zero-hallucination instructions│   │                  │
│    │ │ 3. Call LLM (OpenAI GPT-4)         │    │                  │
│    │ │ 4. Validate response vs facts      │    │                  │
│    │ │ 5. Return AgentDecision            │    │                  │
│    │ └────────────────────────────────────┘    │                  │
│    └────────────────────────────────────────────┘                  │
│                        │                                            │
│                        ▼                                            │
│    return AgentDecision                                            │
│  }                                                                  │
└─────────────────────────────────────────────────────────────────────┘
   │
   ▼
OUTPUT: AgentDecision {
  response_text: string,
  confidence: number,
  reasoning: string,
  sources: string[],
  next_actions: Action[]
}
```
