### Step 2: Database Verification (5 min)

```bash
# Set your database connection
export DATABASE_URL="postgresql://ivylevel:password@localhost:5432/ivylevel_dev"

# Check key tables exist
psql $DATABASE_URL -c "
SELECT COUNT(*) FROM information_schema.tables
WHERE table_schema = 'public'
  AND table_name IN ('students', 'chips', 'growth_events', 'outbox', 'agent_runs');
"
# Expected: 5

# Check facts views exist
psql $DATABASE_URL -c "
SELECT COUNT(*) FROM information_schema.views
WHERE table_schema = 'public'
  AND table_name LIKE 'v_%_facts';
"
# Expected: 4 (v_awards_facts, v_tests_facts, v_gpa_facts, v_deadlines_facts)

# Check RLS enabled
psql $DATABASE_URL -c "
SELECT COUNT(*) FROM pg_tables
WHERE tablename IN ('chips', 'growth_events', 'agent_runs', 'system_events')
  AND rowsecurity = true;
"
# Expected: 4 (all have RLS enabled)
```

## 🆘 TROUBLESHOOTING

### "No such file or directory" errors

**Problem:** Files not found at expected paths

**Solution:**
```bash
# Check current branch
git branch

# If not on v1.0-migration, switch
git checkout v1.0-migration

# Verify latest commit
git log --oneline -1
# Should show: v3.2: Add comprehensive independent verification audit document
```

---

### Database connection errors

**Problem:** `psql: connection refused`

**Solution:**
```bash
# Check PostgreSQL running
pg_isready

# If not running, start it
# macOS: brew services start postgresql
# Linux: sudo systemctl start postgresql

# Test connection
psql $DATABASE_URL -c "SELECT 1;"
```

---

### RLS test shows both students (security violation!)

**Problem:** RLS not enforcing isolation

**Solution:**
```bash
# Verify RLS enabled
psql $DATABASE_URL -c "
SELECT relname, relrowsecurity FROM pg_class
WHERE relname = 'chips';
"
# Should show: chips | t

# If rowsecurity = f, RLS not enabled
# Re-run migration 007
psql $DATABASE_URL -f services/agent-framework/migrations/007_v3.2_production_readiness_facts_views.sql
```

---

### Line counts don't match (±10% difference)

**Problem:** Claimed line counts significantly different

**Acceptable:** ±5% difference (minor formatting changes)
**Unacceptable:** >10% difference (investigate)

**Solution:**
```bash
# Generate detailed line count report
for file in services/agent-framework/src/{chips,db,workers,hgti,resolvers,telemetry,cognition,governance}/*.ts; do
  echo "$file: $(wc -l < $file) lines"
done

```

## 📞 ESCALATION

**If verification fails:**

1. **Document failures:** Note which checks failed in audit document
2. **Check git log:** Verify you're on correct commit (2d138d4 or later)
3. **Review error messages:** Copy exact error output
4. **Open issue:** Create GitHub issue with:
   - Failed check names
   - Error messages
   - Environment details (OS, PostgreSQL version, Node version)

**Critical failures (do not deploy):**
- RLS not enforcing isolation
- PII scrubbing not working
- Database migrations not applied

**Minor failures (can deploy with caution):**
- Line count ±10% difference
- Documentation typos
- Missing optional features
