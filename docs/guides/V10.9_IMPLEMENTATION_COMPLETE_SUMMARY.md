## 🏗️ Architecture & Design Decisions

### 1. Three-Layer Hierarchy

```
Outcomes (Strategic)
  └── Execution Items (Tactical)
        └── Tasks (Operational)
```

**Rationale:** Matches Jenny's coaching framework:
- Outcomes = Long-term strategic goals
- Execution Items = Tactical actions with Five W's
- Tasks = Granular completion units

### 2. Five W's Framework

Every execution item has:
- **Why:** Purpose and motivation
- **What:** Specific deliverable
- **How:** Execution method
- **When:** Deadline/timeframe
- **Who:** Responsible party

**Rationale:** From intelligence extraction - Jenny's tactical solutions framework

### 3. 168-Hour Time Allocation

Weekly time breakdown:
- Total Hours: 168 (7 days × 24 hours)
- Fixed Commitments: Sleep, school, transport, meals
- Available Hours: Flexible allocation for passion projects
- Utilization Tracking: Percentage of hours allocated

**Rationale:** Core framework from Week 1 Planning session (2023-08-02)

### 4. Priority System

- **P0:** Critical (red badge)
- **P1:** High (yellow badge)
- **P2:** Medium (blue badge)
- **P3:** Low (gray badge)

**Rationale:** Strategic Overwhelm Calibration framework

### 5. Completion Tracking

States:
- `not_started`
- `in_progress`
- `completed`
- `blocked`
- `deferred`
- `cancelled`

**Rationale:** Visual progress tracking per weekly action item framework
