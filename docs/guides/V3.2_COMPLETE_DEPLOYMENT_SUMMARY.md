## Rollback Procedures

### Feature-Level Rollback (Preferred)
**Disable specific features without full rollback:**

```bash
# Disable Evidence Panel
VITE_FEATURE_EVIDENCE_PANEL=false

# Disable EQ Layer
VITE_FEATURE_EQ_LAYER=false

# Freeze HGTI weight to zero
VITE_IVYSCORE_VERSION=1

# Rebuild and redeploy
npm run build && npm run start
```

### Emergency Full Rollback (Nuclear Option)
**If critical issues detected:**

1. **Stop frontend:**
   ```bash
   # Kill frontend process
   pkill -f "npm run start"
   ```

2. **Restore pre-v3.2 environment:**
   ```bash
   cd unified-frontend/apps/unified-app
   cp .env.backup .env
   npm run build && npm run start
   ```

3. **Restore database (if needed):**
   ```bash
   # Stop all services first
   PGPASSWORD=postgres psql -h localhost -U postgres -d ivylevel \
     < /tmp/backups/ivylevel_pre_v3.2_20251023_212345.sql
   ```

4. **Notify team:**
   - Post in #engineering channel
   - Update status page
   - Schedule postmortem
