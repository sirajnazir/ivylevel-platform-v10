### 5.3 RLS Isolation Test

```bash
# Test RLS prevents cross-student access
psql "$DATABASE_URL" <<'EOF'
-- Insert test chips for 2 different students
INSERT INTO chips (student_id, kind, source, hash, trace_id)
VALUES
  ('huda-2025', 'SQL', '{"test": "student1"}'::jsonb, 'hash_student1', 'trace1'),
  ('huda-2025-new', 'SQL', '{"test": "student2"}'::jsonb, 'hash_student2', 'trace2')
ON CONFLICT (student_id, hash) DO NOTHING;

-- Set RLS context for student1
SET LOCAL app.student_id = 'huda-2025';

-- Query (should only see student1)
SELECT student_id, hash FROM chips WHERE student_id IN ('huda-2025', 'huda-2025-new');
EOF

# Expected: Only 1 row returned (huda-2025)
# If 2 rows returned: RLS NOT WORKING - ABORT DEPLOYMENT
```

## ⏱️ STEP 7: 48-HOUR MONITORING

### 7.1 Set Up Monitoring Queries

```bash
# Save this as monitor.sh
cat > scripts/monitor.sh <<'MONITOR_SCRIPT'
#!/bin/bash
set -euo pipefail

: "${DATABASE_URL:?Set DATABASE_URL}"

echo "=== v3.2 Monitoring Dashboard ==="
echo "Timestamp: $(date)"
echo ""

# Error rate (last hour)
echo "ERROR RATE (last hour):"
psql "$DATABASE_URL" -c "
SELECT
  COUNT(*) FILTER (WHERE severity = 'ERROR') AS errors,
  COUNT(*) AS total,
  ROUND(100.0 * COUNT(*) FILTER (WHERE severity = 'ERROR') / NULLIF(COUNT(*), 0), 2) AS error_pct
FROM system_events
WHERE created_at > NOW() - INTERVAL '1 hour';
"

# MV refresh status (last hour)
echo ""
echo "MV REFRESH STATUS (last hour):"
psql "$DATABASE_URL" -c "
SELECT event_type, COUNT(*)
FROM system_events
WHERE event_type LIKE 'mv.refresh%'
  AND created_at > NOW() - INTERVAL '1 hour'
GROUP BY event_type;
"

# Outbox backlog
echo ""
echo "OUTBOX BACKLOG:"
psql "$DATABASE_URL" -c "
SELECT COUNT(*) AS undelivered
FROM outbox
WHERE delivered_at IS NULL;
"

# RLS violations
echo ""
echo "RLS VIOLATIONS (should be 0):"
psql "$DATABASE_URL" -c "
SELECT COUNT(*)
FROM system_events
WHERE event_type = 'security.rls_violation'
  AND created_at > NOW() - INTERVAL '1 hour';
"

echo ""
echo "=== End Dashboard ==="
MONITOR_SCRIPT

chmod +x scripts/monitor.sh
```

## 🆘 TROUBLESHOOTING GUIDE

### Issue: Migration 007 fails with "table does not exist"

**Solution:**
```bash
# Check if migration 000 was run

psql "$DATABASE_URL" -f services/agent-framework/migrations/000_v3.2_base_schema.sql

# If not found, run earlier migrations (01-06) first
```

### Issue: RLS test shows both students (security violation!)

**Cause:** RLS not enabled or policies not applied

**Solution:**
```bash
# Verify RLS enabled
psql "$DATABASE_URL" -c "
SELECT relname, relrowsecurity FROM pg_class WHERE relname = 'chips';
"

# If rowsecurity = f, re-run migration 007
psql "$DATABASE_URL" -f services/agent-framework/migrations/007_v3.2_production_readiness_facts_views.sql

# Verify policies exist
psql "$DATABASE_URL" -c "\dp chips"
```
