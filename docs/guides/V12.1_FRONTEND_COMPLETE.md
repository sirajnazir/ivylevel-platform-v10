## Technical Architecture

### Data Flow
```
1. StudentDashboard mounts
2. useEffect triggers on studentId change
3. v10Api.getAssessment("huda-2025") called
4. Fetch to http://localhost:8787/students/huda-2025/assessment
5. Backend queries game_plans table
6. Backend extracts Three Pillar Model + readiness_score
7. Backend calculates Identity from Narrative dimension
8. Backend returns comprehensive assessment JSON
9. Frontend setV12AssessmentData(data)
10. UI re-renders with real data
```

### Type Safety Chain
```
Backend JSONB → API Response → AssessmentData interface → React State → UI Components
```

### Scoring Formula Implementation
**v100 Ivylevel Scoring Table:**
- Aptitude (Academics): 30% × 9/10 = 27 points
- Passion (Extracurriculars): 25% × 10/10 = 25 points
- Service (Leadership): 20% × 8/10 = 16 points
- Identity (Narrative & Fit): 25% × 10/10 = 25 points
- **Total:** 27 + 25 + 16 + 25 = **93 points**

**Note:** Backend returns `overall: 85` which may include additional factors or adjustments beyond the simple linear formula.
