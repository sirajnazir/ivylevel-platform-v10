## 🐛 Troubleshooting

### Issue: Handover Doesn't Trigger

**Symptoms:**
- Assessment completes but GamePlan doesn't activate
- No handover in intelligence logs
- No a2a_handover_log entry

**Diagnosis:**
1. Check if synthesis was delivered:
   ```sql
   SELECT assessment_package FROM multiagent_sessions
   WHERE student_id = 'huda-v26-2025'
   ORDER BY created_at DESC LIMIT 1;
   ```

2. Check backend logs for errors:
   ```bash
   # Should see:
   [V26_A2A] 🔄 A2A Handover detected!
   ```

**Solution:**
- Ensure 7+ messages exchanged
- Student must confirm synthesis with positive response ("Great", "Yes", etc.)
- Check Assessment Agent actually delivered synthesis moment

### Issue: Frontend Doesn't Update

**Symptoms:**
- Handover logged in database
- Backend logs show handover
- But frontend cards don't change

**Diagnosis:**
Check browser console for:
```
[FRONTEND_A2A] 🔄 Handover detected!
```

**Solution:**
1. Hard refresh browser (Cmd+Shift+R / Ctrl+Shift+R)
2. Check if frontend is latest version (v28.0.7)
3. Verify `data.a2a_handover` exists in API response

### Issue: GamePlan Response Generic

**Symptoms:**
- Handover occurs
- GamePlan activates
- But response doesn't mention assessment insights

**Diagnosis:**
Check domain_payload in database:
```sql
SELECT domain_payload FROM a2a_handover_log
WHERE student_id = 'huda-v26-2025'
ORDER BY created_at DESC LIMIT 1;
```

**Solution:**
- Verify Assessment Agent triggered all intelligence types (TYPE-080, 081, 082, 083)
- Check that gaps were extracted (TYPE-082)
- Ensure ivy_score was calculated (TYPE-081)
