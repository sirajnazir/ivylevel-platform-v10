# v10.8: Universal Schema Design - Common App Complete Alignment

**Date:** 2025-10-27
**Version:** v10.8
**Focus:** Universal, extensible schema for all students using Huda's data as reference

---

## Design Philosophy

### Core Principles

1. **Universal Coverage**: Every field works for any student (STEM, Arts, Athletics, Humanities)
2. **Common App First**: All fields map directly to actual application forms
3. **Progressive Tracking**: Capture evolution from Week 1 to graduation
4. **JSONB Flexibility**: No database migrations needed for new students
5. **Reference Implementation**: Huda's complete data validates the schema

---

## 1. Academic Vitals Schema (Universal)

### Why This Design

**Problem with v10.7:**
- Only had: `gpa_weighted`, `gpa_unweighted`, `sat_score`, `ap_count`
- Missing: Class rank, test breakdowns, AP scores by subject, course rigor

**Solution for v10.8:**
- Complete test score tracking (SAT, ACT, AP, IB, etc.)
- Course-level rigor tracking (AP, IB, DE, Honors)
- Progression tracking (GPA trends, test retakes)

### Interface Definition

```typescript
interface AcademicVitals {
  // === GPA (any scale: 4.0, 5.0, 100-point) ===
  gpa_weighted?: number;
  gpa_unweighted?: number;
  gpa_scale: number; // Default 4.0, but supports 5.0, 100, etc.
  gpa_trend?: 'improving' | 'stable' | 'declining';

  // === Class Rank (optional for unranked schools) ===
  class_rank?: number | 'na'; // null means unknown, 'na' means unranked
  class_size?: number;
  percentile?: number; // Calculated: (class_size - rank) / class_size * 100

  // === SAT (optional) ===
  sat?: {
    total?: number; // Superscored
    ebrw?: number; // Evidence-Based Reading and Writing (200-800)
    math?: number; // Math (200-800)
    essay_reading?: number; // Optional essay (2-8)
    essay_analysis?: number;
    essay_writing?: number;
    attempts: {
      date: string; // 'MM/DD/YYYY'
      total: number;
      ebrw: number;
      math: number;
    }[];
  };

  // === ACT (optional) ===
  act?: {
    composite?: number; // Superscored (1-36)
    english?: number;
    math?: number;
    reading?: number;
    science?: number;
    writing?: number;
    attempts: {
      date: string;
      composite: number;
      english: number;
      math: number;
      reading: number;
      science: number;
    }[];
  };

  // === AP Exams (any number of subjects) ===
  ap_exams?: {
    subject: string; // 'Human Geography', 'Calculus AB', etc.
    score: number; // 1-5
    test_date: string; // 'MM/YYYY'
    grade_level: '9' | '10' | '11' | '12';
  }[];

  // === IB Exams (for IB students) ===
  ib_exams?: {
    subject: string;
    level: 'SL' | 'HL'; // Standard or Higher Level
    predicted_score?: number; // 1-7
    final_score?: number; // 1-7
    test_date?: string;
    grade_level: '11' | '12';
  }[];

  // === Subject Tests (SAT Subject, if applicable) ===
  subject_tests?: {
    subject: string;
    score: number;
    test_date: string;
  }[];

  // === Current Course Load (updated each year) ===
  current_courses?: {
    year: '9' | '10' | '11' | '12' | 'PG';
    semester: 'fall' | 'spring' | 'full_year';
    courses: {
      subject: string; // 'ENG', 'MATH', 'SCI', 'HIST', 'LANG', 'COMPSCI', 'OTH/ELE'
      title: string; // Full course name
      level: 'REG' | 'HONORS' | 'AP' | 'IB' | 'DE'; // Dual Enrollment
      credits?: number; // For college courses
    }[];
  }[];

  // === Cumulative Stats (auto-calculated) ===
  total_ap_courses?: number; // Count of AP courses taken
  total_ib_courses?: number;
  total_honors_courses?: number;
  total_de_courses?: number; // Dual enrollment
  academic_rigor_score?: number; // Calculated: weighted sum of advanced courses
}
```

- Only had 5 activities for Huda
- Missing: Sunday School, JCamp, Women in Games, Podcast, TikTok

- Track activities from founding to application
- Link programs and activities (JCamp is both)

2. `arts_music` - Band, orchestra, theater, visual arts

9. `other_club` - Student government, general clubs
10. `research` - Lab work, independent research
11. `student_government` - Class president, ASB
12. `work` - Part-time jobs, family business

## 3. Program Schema (Summer Programs, Competitions)

### Why Separate from Activities

**Programs are:**
- Time-bounded (specific weeks/dates)
- Selective (acceptance rates matter)
- Credential-generating (certificates, recommendations)
- Often linked to activities (JCamp → Journalism, KWK → CS)

**But they ALSO appear as activities on Common App**

### Interface Definition

```typescript
interface ProgramDetail {
  // Identity
  name: string;
  program_type: 'summer' | 'year_round' | 'weekend' | 'online' | 'competition';
  category: 'academic' | 'research' | 'leadership' | 'arts' | 'stem' | 'pre_college' | 'internship';

  // Selection
  selection_rate?: number; // 0.01 = 1% acceptance
  total_applicants?: number;
  total_accepted?: number;

  // Timeline
  attended_week?: number; // Week in high school journey
  start_date?: string;
  end_date?: string;
  grade_level: '9' | '10' | '11' | '12' | 'PG';

  // Details
  institution?: string; // Host org/university
  location?: string;
  is_paid?: boolean; // Paid program vs scholarship
  cost?: number;
  scholarship_amount?: number;
  hours_total?: number;

  // Outcomes
  outcomes?: {
    projects_completed?: number;
    papers_published?: number;
    presentations?: number;
    skills_learned?: string[];
    recommendation_received?: boolean;
  };

  // Link to activity (if applicable)
  related_activity_name?: string; // 'JCamp (AAJA)' links to activity
}
```

## 5. Extraction Logic (From Session Transcripts)

### Universal Patterns for Any Student

**Academic Data Extraction:**
```
Pattern: "I got a {score} on the {test_name}"
→ Extract: test_type, score, date

Pattern: "I'm taking AP {subject} this year"
→ Extract: subject, grade_level, status='current'

Pattern: "My GPA is {number}"
→ Extract: gpa, determine if weighted/unweighted from context
```

**Activity Data Extraction:**
```
Pattern: "I founded {org_name} to {purpose}"
→ Extract: name, activity_type=infer, position='Founder', founded_week=current

Pattern: "We raised {amount} for {cause}"
→ Extract: funding_raised, impact category

Pattern: "I volunteer {hours} hours per week at {place}"
→ Extract: hours_per_week, activity_type='community_service'
```

**Program Data Extraction:**
```
Pattern: "I attended {program_name} this summer"
→ Extract: name, program_type='summer', attended_week=estimate

Pattern: "I was selected for {program} (top {percentage}%)"
→ Extract: name, selection_rate=percentage/100
```

## 6. UI Rendering Logic (Works for Any Student)

### Academic Profile Card

```typescript
function AcademicProfileCard({ vitals }: { vitals: AcademicVitals }) {
  return (
    <Card>
      <h3>Academic Profile</h3>

      {/* GPA - always show if available */}
      {vitals.gpa_weighted && (
        <Metric>
          <Label>GPA (Weighted)</Label>
          <Value>{vitals.gpa_weighted.toFixed(2)} / {vitals.gpa_scale}</Value>
        </Metric>
      )}

      {/* Class Rank - show if available */}
      {vitals.class_rank !== undefined && (
        <Metric>
          <Label>Class Rank</Label>
          <Value>
            {vitals.class_rank === 'na' ? 'Unranked' : `${vitals.class_rank} / ${vitals.class_size}`}
          </Value>
        </Metric>
      )}

      {/* SAT - show if student took SAT */}
      {vitals.sat?.total && (
        <Metric>
          <Label>SAT</Label>
          <Value>{vitals.sat.total}</Value>
          <Breakdown>
            EBRW: {vitals.sat.ebrw} | Math: {vitals.sat.math}
          </Breakdown>
        </Metric>
      )}

      {/* ACT - show if student took ACT */}
      {vitals.act?.composite && (
        <Metric>
          <Label>ACT</Label>
          <Value>{vitals.act.composite}</Value>
        </Metric>
      )}

      {/* AP Exams - show if any taken */}
      {vitals.ap_exams && vitals.ap_exams.length > 0 && (
        <Section>
          <h4>AP Exams</h4>
          {vitals.ap_exams.map(exam => (
            <APScore key={exam.subject}>
              {exam.subject}: <strong>{exam.score}</strong> (Grade {exam.grade_level})
            </APScore>
          ))}
        </Section>
      )}

      {/* Current Courses */}
      {vitals.current_courses && (
        <Section>
          <h4>Current Courses</h4>
          {vitals.current_courses.map(term => (
            <CourseList key={term.semester}>
              <h5>{term.semester === 'fall' ? 'Fall' : 'Spring'} Semester</h5>
              {term.courses.map(course => (
                <Course key={course.title} level={course.level}>
                  {course.title} ({course.level})
                </Course>
              ))}
            </CourseList>
          ))}
        </Section>
      )}
    </Card>
  );
}
```

```typescript
function calculateCompletenessScore(weekData: WeeklyVitals): number {
  let score = 0;
  let total = 0;

  // Academic (40 points possible)
  if (weekData.academic_vitals?.gpa_weighted) score += 10;
  if (weekData.academic_vitals?.sat || weekData.academic_vitals?.act) score += 10;
  if (weekData.academic_vitals?.ap_exams?.length) score += 10;
  if (weekData.academic_vitals?.current_courses?.length) score += 10;
  total += 40;

  // Activities (40 points possible)
  const ecCount = weekData.ec_details?.length || 0;
  score += Math.min(ecCount * 4, 40); // 4 points per activity, max 40
  total += 40;

  // Programs (20 points possible)
  const progCount = weekData.program_details?.length || 0;
  score += Math.min(progCount * 10, 20);
  total += 20;

  return (score / total) * 100;
}
```
