## Implementation Details

### 1. IntentRouterService

**File:** `services/agent-framework/src/routing/IntentRouterService.ts` (180 lines)

**Capabilities:**
- LLM-based intent classification using GPT-3.5-turbo (10x cheaper than GPT-4)
- 8 intent types: gameplan_strategy, ec_discovery, essay_help, scholarship_search, schedule_optimization, mental_health, assessment, clarification_needed
- Confidence scoring (0-1)
- Strategy node routing
- Batch classification support

**Key Methods:**
```typescript
classifyIntent(query, context): Promise<IntentClassification>
routeToStrategyNode(intent): Promise<string>
batchClassify(queries): Promise<IntentClassification[]>
```

**Cost:** ~$0.01 per 100 classifications

**Example Usage:**
```typescript
const router = new IntentRouterService();
const intent = await router.classifyIntent(
  "I'm overwhelmed with college apps",
  { student_id: 'huda', archetype: 'high_achiever', grade: 11, burnout_level: 0.35 }
);
// → { intent_slug: 'gameplan_strategy', confidence: 0.92, ... }
```

### 2. ContextEngineeringPipeline

**File:** `services/agent-framework/src/context/ContextEngineeringPipeline.ts` (350 lines)

**Capabilities:**
- Semantic search for few-shot examples (Pinecone vector DB)
- SQL-grounded facts extraction (zero hallucination)
- Coach persona adaptation (Jenny's EQ profile)
- Automatic context compression (6000 token limit)
- Token estimation

**Pipeline Steps:**
1. Retrieve few-shot examples (semantic similarity search)
2. Extract SQL-grounded facts (student GPA, SAT, ECs, etc.)
3. Build system prompt (coach persona + student context)
4. Compress if needed (reduce few-shot examples)

**Key Methods:**
```typescript
constructOptimalContext(
  strategyNodeType,
  studentContext,
  coachPersona
): Promise<EngineeredContext>
```

**Output:**
```typescript
{
  system_prompt: string,          // Persona-adapted system prompt
  few_shot_examples: Array<...>,  // Top 3 similar coaching examples
  grounding_facts: string[],      // SQL facts (GPA, SAT, ECs)
  context_length_tokens: number,  // Token count
  compression_applied: boolean    // Was context compressed?
}
```

**Cost:** ~$0.002 per context construction (embedding API call)

### 3. ReflectionService

**File:** `services/agent-framework/src/reflection/ReflectionService.ts` (300 lines)

**Capabilities:**
- Producer-Critic quality improvement loop
- Producer: GPT-4 generates response
- Critic: Claude 3.5 Sonnet evaluates quality
- 4 evaluation criteria: actionable, empathetic, data_grounded, ivyscore_optimal
- Iterative refinement (max 3 iterations)
- Human escalation when quality threshold not met

**Key Methods:**
```typescript
generateWithReflection(
  initialResponse,
  context,
  options: { max_iterations, quality_threshold }
): Promise<ReflectionResult>
```

**Evaluation Criteria:**
- **Actionable** (0-1): Specific, concrete next steps?
- **Empathetic** (0-1): Acknowledges student emotions?
- **Data Grounded** (0-1): Based on actual student data?
- **IvyScore Optimal** (0-1): Maximizes admission probability?

**Quality Gate:**
- Default threshold: 0.8/1.0
- Max iterations: 3
- Escalation: Warning returned if threshold not met

**Cost:** ~$0.04 per reflection cycle (avg 1.8 iterations)

**Example Output:**
```typescript
{
  final_response: "...",           // Refined response
  quality_score: 0.87,             // Overall quality (0-1)
  iterations_needed: 2,            // How many iterations
  critiques: [...],                // All critique cycles
  warning: undefined               // Or escalation message
}
```

### 4. StrategyOrchestrator

**File:** `services/agent-framework/src/orchestration/StrategyOrchestrator.ts` (320 lines)

**Capabilities:**
- End-to-end pipeline orchestration
- 6-step execution flow
- Streaming support (real-time UX)
- Comprehensive error handling
- Performance tracking

**Execution Pipeline:**
```
1. Intent Classification (IntentRouterService)
   ↓
2. Strategy Node Routing
   ↓
3. Context Engineering (ContextEngineeringPipeline)
   ↓
4. Strategy Execution (GPT-4 response generation)
   ↓
5. Reflection Loop (ReflectionService quality gate)
   ↓
6. Voice Adaptation (optional ToneAdapterTool)
   ↓
Final Response
```

**Key Methods:**
```typescript
execute(input): Promise<StrategyExecutionOutput>
executeStreaming(input): AsyncGenerator<{type, content}>
```

**Input:**
```typescript
{
  student_query: string,
  student_id: string,
  coach_id: string
}
```

**Output:**
```typescript
{
  response: string,                    // Final coaching response
  metadata: {
    intent: string,                    // Classified intent
    strategy_node: string,             // Strategy used
    reflection_iterations: number,     // Quality iterations
    quality_score: number,             // Final quality (0-1)
    total_duration_ms: number,         // Latency
    context_tokens: number             // Context size
  }
}
```

**Performance Target:** <10s end-to-end latency (p95)

**File:** `services/agent-framework/src/caching/CacheService.ts` (150 lines)

**Capabilities:**
