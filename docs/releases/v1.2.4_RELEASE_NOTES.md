# v1.2.4 Release Notes - Inline Report Delivery

## Overview

Version 1.2.4 makes opportunity analytics accessible through the API, agent, and UI. Reports are no longer just files - they're integrated into the platform for real-time access by coaches, students, and parents.

## Key Features

### 1. Reports API Endpoint

```bash
GET /reports/:studentId?type={yield|temporal}
```

Returns JSON reports with:
- **Yield Report**: Category performance, win rates, insights
- **Temporal Report**: Weekly patterns, bombardment analysis, rebounds

Example:
```bash
curl http://localhost:4000/reports/huda?type=yield
```

### 2. Agent Integration

The agent now responds to report queries inline:

**User**: "What's my opportunity success rate?"
**Agent**: "Overall win rate: 89.2% across 83 applications

| Category | Applications | Accepted | Win Rate |
|----------|--------------|----------|----------|
| Honor Societies | 8 | 8 | 100.0% |
| Summer Programs | 12 | 10 | 83.3% |
| Research | 5 | 2 | 40.0% |

High-yield categories: Honor Societies, Summer Programs
Challenging categories: Research (needs 3x buffer strategy)"

### 3. Nightly Report Generation

```bash
# Run manually
npx ts-node cron/recompute.ts

# Or schedule with cron
0 2 * * * cd /app && npx ts-node cron/recompute.ts
```

Performs:
- Vitals recomputation for all students
- Report generation and caching
- Previous report backup
- Markdown report creation

### 4. UI Card Specification

New "Reports" tab in coach dashboard with:
- **Opportunity Yield Card**: Category breakdown with visual indicators
- **Temporal Patterns Card**: Timeline chart showing application cycles
- Color coding: Green (80%+), Amber (<50%), Blue (bombardment)

## Usage Examples

### Get Yield Report
```javascript
const response = await fetch('/reports/huda?type=yield');
const report = await response.json();

console.log(`Win rate: ${report.summary.overallWinRate}%`);
report.categories.forEach(cat => {
  console.log(`${cat.category}: ${cat.win_rate_pct}%`);
});
```

### Get Temporal Report
```javascript
const response = await fetch('/reports/huda?type=temporal');
const report = await response.json();

console.log(`Bombardment weeks: ${report.summary.bombardmentWeeks}`);
console.log(`Rejection rebounds: ${report.summary.rejectionRebounds}`);
```

### Agent Queries
- "Show me my opportunity success rate by category"
- "What were my bombardment week results?"
- "How many rejection rebounds did I have?"
- "Which categories have the highest acceptance rate?"
