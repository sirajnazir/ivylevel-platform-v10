# Ivylevel v4.6.1: College & Scholarship Layer + Readiness Correlation

**Release Date:** 2025-10-04
**Version:** v4.6.1
**Status:** ✅ Production Ready

---

## Overview

v4.6.1 introduces a complete, normalized, extensible subsystem to represent college admissions data with full Huda data seeded — supporting future readiness linking, predictions, and outcomes intelligence.

This release provides:
- **College List Tracking**: Canonical representation of every school a student applies to
- **Scholarship Management**: Complete tracking of all scholarships applied/received
- **Readiness Correlation**: Links college outcomes with IvyReady snapshots for predictive analytics
- **Conversational Queries**: Natural language support for college and scholarship queries

---

## Database Schema

### Tables

#### `college_list`
Canonical list of every school a student applies to.

| Column | Type | Description |
|--------|------|-------------|
| `college_id` | SERIAL PRIMARY KEY | Unique identifier |
| `student_id` | TEXT | Reference to students table |
| `college_name` | TEXT | Name of the college |
| `bucket_category` | TEXT | Wild Card, Reach, Match, Safety |
| `decision_plan` | TEXT | EA, ED, RD, REA, Rolling |
| `decision_result` | TEXT | Accepted, Rejected, Waitlisted, Deferred, Withdrawn, Pending |
| `waitlist` | BOOLEAN | Whether student was waitlisted |
| `program` | TEXT | Program applied to |
| `supplements` | TEXT | Required supplemental essays |
| `location` | TEXT | College location |
| `acceptance_rate` | NUMERIC | College acceptance rate |
| `interview_status` | TEXT | Interview requirement/status |
| `ivyready_score_at_submit` | NUMERIC | Student's readiness score at submission |
| `created_ts` | TIMESTAMPTZ | Record creation timestamp |

#### `scholarships`
Tracks all scholarships applied/received.

| Column | Type | Description |
|--------|------|-------------|
| `scholarship_id` | SERIAL PRIMARY KEY | Unique identifier |
| `student_id` | TEXT | Reference to students table |
| `scholarship_name` | TEXT | Name of scholarship |
| `sponsor_org` | TEXT | Sponsoring organization |
| `amount_usd` | NUMERIC | Scholarship amount in USD |
| `application_status` | TEXT | Applied, Accepted, Rejected, Pending |
| `decision_date` | DATE | Decision notification date |
| `notes` | TEXT | Additional notes |
| `created_ts` | TIMESTAMPTZ | Record creation timestamp |

### Views

#### `v_college_readiness_correlation`
Measures relationship between admission outcomes and student readiness metrics.

**Purpose**: Enable predictive modeling by correlating:
- SAT/GPA scores
- IvyReady overall score
- Individual feature strengths (academics, ECs, awards)
- College acceptance rates
- Admission outcomes

**Key Columns**:
- `acceptance_numeric`: Quantified outcome (1.0 = Accepted, 0.5 = Waitlisted, 0 = Rejected)
- `relative_strength`: Feature value relative to target (feature_value / target_value)
- `ivyready_score_at_submit`: Snapshot of readiness at submission time

#### `v_scholarship_impact`
Analyzes scholarship effect on affordability and readiness outcomes.

**Purpose**: Quantify scholarship value and integrate into readiness scoring.

**Key Columns**:
- `affordability_boost`: Scholarship value / 1000 (normalized impact score)
- `adjusted_readiness_score`: Overall score + (scholarship_amount / 5000)

## Conversational API

### Supported Intents

The system supports natural language queries through the Jenny Agent router:

| Query Example | Intent | Parameters |
|---------------|--------|------------|
| "Which of my colleges accepted me?" | `college.list` | `{ "decision_result": "Accepted" }` |
| "Which of my match schools accepted me?" | `college.list` | `{ "category": "Match", "decision_result": "Accepted" }` |
| "Which reach schools waitlisted me?" | `college.list` | `{ "category": "Reach", "decision_result": "Waitlisted" }` |
| "Show me scholarships I received." | `scholarship.list` | `{ "application_status": "Accepted" }` |
| "Compare my readiness with schools that accepted me." | `college.compare.readiness` | `{}` |
| "How much scholarship money did I receive?" | `scholarship.total` | `{ "application_status": "Accepted" }` |

### API Endpoints

**GET /students/:id/college_outcomes**

Returns all colleges with result, category, and readiness context.

```json
{
  "college_name": "UC Irvine",
  "bucket_category": "Reach",
  "decision_result": "Accepted",
  "ivyready_score_at_submit": 90.6,
  "acceptance_rate": 20.0,
  "readiness_factor_rank": {
    "academics": 92,
    "ecs": 90,
    "awards": 88
  }
}
```

**Supported Query Parameters**:
- `category`: match|reach|safety
- `decision_result`: accepted|rejected|waitlisted
- `include_readiness`: true|false

**GET /students/:id/scholarships**

Returns awarded scholarships with readiness boost.

```json
{
  "scholarship_name": "UIUC Chancellor's Scholarship",
  "sponsor_org": "University of Illinois",
  "amount_usd": 10000,
  "status": "Accepted",
  "affordability_boost": 2.0,
  "adjusted_readiness_score": 92.6
}
```

## Integration with Existing Systems

### Readiness Snapshots
College outcomes are linked to `ivyready_snapshots` via:
- `student_id` foreign key relationship
- `snapshot_phase = 'final_submit'` for submission-time readiness

### Intent Router
Conversational intents defined in:
- `services/jenny-api/src/intent/college_scholarship_intents.json`

Integrate into existing router by importing and adding to intent registry.

### Feature System
Readiness correlation leverages:
- `v_features_all`: Aggregated feature view
- `readiness_feature_weights`: Target values for normalization
- Computed `relative_strength` metric for predictive modeling

## Testing

### Sample Queries

```sql
-- Which match schools did Huda get accepted to?
SELECT college_name, decision_result, acceptance_rate
FROM college_list
WHERE student_id = 'huda-2025'
  AND bucket_category = 'Match'
  AND decision_result = 'Accepted';

-- What's the total accepted scholarship amount?
SELECT SUM(amount_usd) AS total_scholarships
FROM scholarships
WHERE student_id = 'huda-2025'
  AND application_status = 'Accepted';

-- Compare readiness scores for accepted vs rejected schools
SELECT
  decision_result,
  AVG(acceptance_rate) AS avg_acceptance_rate,
  COUNT(*) AS count
FROM college_list
WHERE student_id = 'huda-2025'
GROUP BY decision_result;
```
