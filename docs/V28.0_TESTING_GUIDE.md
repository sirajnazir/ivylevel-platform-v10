## 🔍 Troubleshooting

### Issue: Handover Not Triggering

**Symptoms:**
- Assessment completes but GamePlan Agent doesn't respond
- No A2A logs in console

**Diagnosis:**
```sql
-- Check if synthesis was delivered (use clone student_id)
SELECT
  id,
  student_id,
  current_phase,
  current_agent,
  status,
  assessment_package->'synthesis_delivered' as synthesis_delivered,
  analytics->'total_messages' as message_count
FROM multiagent_sessions
WHERE student_id = 'huda-v26-2025'
ORDER BY created_at DESC LIMIT 1;
```

**Possible Causes:**
1. Not enough assessment depth (need 6+ messages)
2. Synthesis not confirmed by student
3. Missing required facts (grade, school, interests)

**Solution:**
- Continue assessment with more detail
- Student must confirm synthesis with "yes" or "that's right"

### Issue: GamePlan Response Generic

**Symptoms:**
- GamePlan Agent responds but doesn't mention assessment insights
- P0 gaps not shown

**Diagnosis:**
```sql
-- Check domain_payload contents (use clone student_id)
SELECT domain_payload FROM a2a_handover_log
WHERE student_id = 'huda-v26-2025'
ORDER BY created_at DESC LIMIT 1;
```

**Possible Causes:**
1. Intelligence types (TYPE-081, 082, 083) didn't trigger
2. Gaps not extracted from TYPE-082

**Solution:**
- Check console logs for intelligence triggers
- Verify TYPE-080, 081, 082, 083 all triggered during assessment

### Issue: Backend Crashes

**Symptoms:**
- Server stops responding
- tsx process exits

**Diagnosis:**
```bash
# Check last error in logs
tail -50 /path/to/logs/error.log

# Check TypeScript compilation
cd /Users/snazir/ivylevel-platform-v10/services/agent-framework
npm run build
```

**Possible Causes:**
1. TypeScript compilation errors in A2A code
2. Missing environment variables
3. Database connection issues

**Solution:**
- Fix TypeScript errors
- Verify DATABASE_URL set correctly
- Check PostgreSQL is running
