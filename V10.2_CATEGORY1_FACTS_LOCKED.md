## Architecture Alignment

### ✅ Facts-First Routing (UTFA)

**Flow:**
```
Test Chat UI (Next.js, port 3000)
   ↓ HTTP POST /agent/chat/gpt5
Jenny API Server (Express, port 8787)
   ↓
intentRouter.ts (Fact Guardrails → GPT-5 Classification)
   ↓
agentChat-utfa.ts (Orchestrator with Deduplication)
   ↓
resolvers/compat.ts (Compat Resolvers)
   ↓
compat.* Views (Bridge to vital_facts)
   ↓
PostgreSQL Database
   ↓
compose.ts (Answer Composition + Meta-Stripping)
   ↓
Response to UI
```

### ✅ Production Boundaries

- ✅ Backend logic: `/services/jenny-api/` ONLY
- ✅ UI: `/apps/test-chat-ui/` (thin HTTP client)
- ✅ No business logic in test-chat-ui
- ✅ Resolvers split by domain (awards, ecs, programs, academics)

### ✅ Source Gating & Provenance

- ✅ Views expose source_ids (SRC-*)
- ✅ Temporal resolution (first/latest/nth/as-of) via UTFA
- ✅ Provenance tracking (source_id, created_ts)
