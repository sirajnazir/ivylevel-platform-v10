### 2. Resolver Integration

**New File:** `services/jenny-api/src/resolvers/compat.ts`

Implements complete resolver API compatible with v3.0:

```typescript
// Awards
awards.initial()      → [] (not in compat layer yet)
awards.final()        → compat.v_awards_final
awards.progression()  → [] (not in compat layer yet)

// ECs
ecs.initial()         → [] (not in compat layer yet)
ecs.final()           → compat.v_kb_items WHERE item_type='ec'
ecs.progression()     → [] (not in compat layer yet)

// Programs
programs.initial()    → [] (not in compat layer yet)
programs.submitted()  → compat.v_kb_items WHERE item_type='program'
programs.final()      → compat.v_kb_items WHERE item_type='program'
programs.decisions()  → [] (not in compat layer yet)
programs.progression()→ [] (not in compat layer yet)

// Academics
academics.gpa.latest()      → compat.v_academics_latest
academics.gpa.initial()     → compat.v_academics_series (first entry)
academics.gpa.final()       → compat.v_academics_latest (alias)
academics.gpa.progression() → compat.v_academics_series

academics.sat.ordinal(n)    → compat.v_sat_timeline WHERE attempt_number=n
academics.sat.latest()      → compat.v_academics_latest
academics.sat.progression() → compat.v_sat_timeline

academics.summary()         → compat.v_academics_latest

// Progression
progression.timeline()      → compat.v_academics_series
```

## Key Technical Details

### Schema Lock (DDL Blocking)

To prevent schema drift, DDL commands are blocked unless running in migration mode:

```sql
CREATE EVENT TRIGGER et_ddl_block ON ddl_command_start
WHEN TAG IN ('CREATE TABLE', 'ALTER TABLE', 'DROP TABLE', ...)
EXECUTE PROCEDURE compat.block_ddl();
```

**Usage:**
```sql
-- Migrations only:
SET app.migration = 'true';
-- DDL commands allowed here
SET app.migration = 'false';

-- Normal operations:
-- DDL blocked with error: "DDL blocked: run DDL only via migrations"
```
