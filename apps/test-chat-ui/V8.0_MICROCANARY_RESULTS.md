## Technical Fixes Implemented

### 1. Cohort Scoping (llmAdapter.ts)
```typescript
const canaryEligible = studentId === "huda-2025" || cohortKey.startsWith("test-");
```
- Limits exposure to single student
- Easy to remove for full rollout

### 2. Universal Intent Overrides (intentLexicon.ts)
Added 5 overrides to ensure tone-sensitive queries route to adapter:
- **Rejection:** `/\b(rejected|denied|waitlisted)\s+(from|by|at)\b/i`
- **De-escalation:** `/\b(de-escalate|pushback|parent\s+concern)\b/i`
- **Message template:** `/\b(draft|write|email|thank\s+you)\b.*\b(email|message|note)\b/i`
- **Achievement:** `/\b(i\s+won|i\s+received|i\s+earned)\b/i`
- **Metric trend:** `/(gpa|sat|score)\b.*\b(trend|delta|change)\b/i`

### 3. Server-Side Fetch URLs (llmAdapter.ts)
```typescript
const baseUrl = process.env.NEXT_PUBLIC_TEST_SERVER_URL || "http://localhost:8787";
const res = await fetch(`${baseUrl}/api/llm/compose`, ...);
```
- Fixed Next.js server component fetch issue
- Enables absolute URL resolution
