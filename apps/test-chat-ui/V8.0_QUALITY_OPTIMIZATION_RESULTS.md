## Detailed Response Analysis

### 1. Rejection Response ✅ GOOD

**Query:** "I got rejected from Stanford"
**Intent Match:** ✅ rejection_response (universal override working)

**Adapter Response 1:**
```
I'm with you. Respond in 2 sentences: (1) Acknowledge the rejection and
validate the feelings; (2) Reinforce that many successful peers faced
similar setbacks and that this doesn't define worth or future potential.

Next 10-minute step: Review your remaining applications...
```
**Issue:** Too instructional/meta (sounds like a system prompt leaked)

**Adapter Response 2:**
```
I'm with you. Stanford rejection is common; 94% applicants don't get in.
Share a 'what I learnt' reflection with 1 concrete change for next apps.
```
✅ **Better:** Concise, specific, actionable with implicit next step

### 5. Fact Queries ❌ FAIL

**All 3 fact queries** (awards, GPA, SAT) returned low-confidence scaffolds:

**Example (Awards):**
```
## 168-Hour Framework
**Breakdown (W001-FRAMEWORK-168HOUR)**:
- After school (8h), sleep (8h), homework (4h), basics (2h) ⇒ **~2 hours/day**...
```

**Root Cause:** Queries not matching SQL-backed intents, falling back to generic scaffolds

**Current Intent Matching:**
- "What awards did I win?" → `execution_framework, tactic` (wrong!)
- "What's my current GPA?" → `assessment, strategy` (wrong!)
- "First vs last SAT..." → ✅ `academics, trend` (correct, but no data)

**Fix Needed:** Update intent lexicon to route fact queries correctly:
```yaml
- name: awards_query
  match: ["\\b(what|which|list)\\s+(awards?|honors?|recognitions?)"]
  addTags: ["awards", "facts.canonical"]
  preferTypes: ["sql"]
```

## Guard System Performance

1. **Warmth Guard:** All responses contain warmth cue ("I'm with you")
2. **Action Guard:** Successfully adding "Next 10-minute step..." when missing
3. **Internals Stripping:** Chip IDs being cleaned (mostly - see issue)
4. **Proof Guard:** Adding "As of" + "Sources" to fact queries

### ⚠️ Issues Found

1. **Chip IDs still appearing in some responses:**
   ```
   (W001-FRAMEWORK-168HOUR)
   @ KBv6_2025-10-06_v1.0
   ```
   Pattern `\([A-Z]\d{3}-[A-Z]+-\d{3}\)` should catch this, but format varies

2. **Meta instructions leaking:**
   ```
   "Respond in 2 sentences: (1) Acknowledge... (2) Reinforce..."
   ```
   This looks like the fast-path system prompt leaked into response

## Recommendations

### Immediate Fixes (< 5 min)

1. **Add parent conflict intent override** (intentLexicon.ts):
```typescript
const parentConflict = /\b(parent|mom|dad|family).*(say|think|believe|upset|angry|conflict|pushback|waste|wasting)/i;
if (parentConflict.test(query)) {
  console.log(`[IntentLexicon] Universal override: parent_conflict → escalation`);
  tags.add("escalation");
  tags.add("parent_brief");
  return { tags: [...tags], preferTypes: [] };
}
```

2. **Fix fact query intent routing** (add to intent_lexicon.yaml):
```yaml
- name: awards_query_facts
  match: ["\\b(what|which|list|show).*(awards?|honors?|recognitions?|won|received)"]
  addTags: ["awards", "facts.canonical"]
  preferTypes: ["sql"]

- name: gpa_query_facts
  match: ["\\bGPA\\b|grade point average|weighted|unweighted"]
  addTags: ["academics", "facts.canonical"]
  preferTypes: ["sql"]

- name: testing_query_facts
  match: ["\\b(SAT|ACT|test score).*(first|last|delta|change|timeline|progression)"]
  addTags: ["testing", "facts.canonical"]
  preferTypes: ["sql"]
```

3. **Enhance internal stripping patterns** (composerGuards.ts):
```typescript
const INTERNAL_PATTERNS = [
  /\b[A-Z]\d{3}-[A-Z]+-\d{3,6}\b/g,     // W015-STRATEGY-001
  /\([A-Z]\d{3}-[A-Z]+-\d{3,6}\)/g,     // (W015-STRATEGY-001)
  /chip_id:\s?[A-Z0-9\-]+/gi,
  /scaffold\.[a-z_.]+/gi,
  /@\s?KBv\d+[^\s]*/g,                  // @ KBv6_2025-10-06_v1.0
  /\*\*Breakdown\s?\([A-Z0-9\-]+\)\*\*/gi,  // **Breakdown (W001-FRAMEWORK-168HOUR)**
];
```
